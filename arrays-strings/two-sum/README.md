# Two Sum

**Difficulty:** Easy

**LeetCode Link:** https://leetcode.com/problems/two-sum/submissions/2142686957/

## Approach

The program uses two loops to check every possible pair of elements.

If the sum of two elements is equal to the target, their indices are printed.

## Time Complexity

O(n²)

## Space Complexity

O(1)
